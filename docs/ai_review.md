# Разбор модели публикации, предложенной ИИ-ассистентом

Исходный файл: `sandbox/ai_publication.py`.

| № | Ошибка | Последствие | Подтверждение | Исправление |
|---:|---|---|---|---|
| 1 | Вызов `title.normalize()` | У строки нет такого метода | Статический анализ mypy и вызов функции | Использовать существующий метод или функцию нормализации |
| 2 | Год задан строкой | Принимаются текстовые значения года | Создать объект с текстовым годом | Использовать `int | None` |
| 3 | Нет проверки названия | Допускается пустое название | Создать публикацию с пустой строкой | Проверять название в `__post_init__` |
| 4 | DOI по умолчанию задан пустой строкой | Не различаются отсутствие DOI и пустое значение | Проверить значение по умолчанию | Использовать `str | None` |
| 5 | Авторы хранятся одной строкой | Нельзя надёжно работать с отдельными авторами | Проверить тип поля | Использовать `list[str]` |
| 6 | ISSN представлен одной строкой | Неудобно хранить несколько ISSN | Проверить запись с несколькими ISSN | Использовать `issns: list[str]` |
| 7 | Сравнение выполняется только по названию | Разные публикации могут ошибочно считаться одинаковыми | Сравнить записи с различными DOI | Сопоставлять нормализованные DOI |
| 8 | Идентификаторы не нормализуются | Различные формы записи одного DOI могут считаться разными | Сравнить DOI с URL-префиксом и без него | Использовать функции нормализации |
| 9 | Нет проверки значений при создании объекта | Модель принимает некорректные данные | Создать объект с неверным годом и пустым названием | Добавить проверки в `__post_init__` |

## Подтверждение

Команда `uv run mypy sandbox/ai_publication.py` позволяет проверить вызов несуществующего метода `normalize`. Некорректные значения года и названия проверяются созданием тестовых объектов.
